# Plan Your Escape 旅游网站 - 前端答辩稿

## 一、项目介绍

大家好，我是前端开发负责人。我们开发的"Plan Your Escape"是一个完整的旅游预订平台，采用前后端分离架构，我负责Vue.js前端部分的开发。

### 项目技术栈
- **前端框架**: Vue 3 + TypeScript + Composition API
- **UI样式**: Tailwind CSS + Heroicons
- **路由管理**: Vue Router
- **状态管理**: Pinia
- **HTTP请求**: Axios
- **构建工具**: Vite

## 二、功能模块介绍

### 1. 用户认证模块
- **登录注册**: 实现了完整的用户注册、登录功能
- **表单验证**: 前端实时验证邮箱格式、密码强度、用户名唯一性
- **密码找回**: 支持忘记密码重置功能
- **角色区分**: 支持普通用户和管理员两种角色，不同权限访问不同页面

### 2. 首页展示模块
- **响应式设计**: 适配桌面端和移动端
- **目的地展示**: 动态加载热门旅游目的地，支持4个和2个目的地的不同布局
- **搜索引导**: 引导用户进入预订流程

### 3. 产品搜索预订模块
- **智能搜索**: 支持按目的地、日期、人数、价格区间筛选
- **产品展示**: 展示酒店和旅游产品，包含图片、评分、价格等信息
- **收藏功能**: 用户可以收藏感兴趣的产品
- **预订流程**: 完整的订单创建流程，包含联系人信息填写

### 4. 个人中心模块
- **我的行程**: 显示用户的真实订单数据，支持订单状态管理
- **订单操作**: 可以查看订单详情、取消未确认订单
- **数据统计**: 展示总行程数、已完成数、消费总额等统计信息
- **个人资料**: 支持修改个人信息和密码

### 5. 管理后台模块
- **仪表盘**: 展示系统总体数据统计
- **产品管理**: 管理员可以增删改查旅游产品，支持图片上传
- **用户管理**: 管理用户账户，支持禁用、删除等操作
- **订单管理**: 查看和管理所有用户订单
- **文件管理**: 支持图片上传和管理

### 2. 路由守卫与权限控制
```typescript
// 实现路由级别的权限控制
router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()
  
  if (to.meta.requiresAuth && !authStore.isLoggedIn) {
    next('/login')
  } else if (to.meta.requiresAdmin && authStore.user?.role !== 'ADMIN') {
    next('/')
  } else {
    next()
  }
})
```

### 3. 状态管理
```typescript
// 使用Pinia进行全局状态管理
export const useAuthStore = defineStore('auth', () => {
  const user = ref(null)
  const token = ref('')
  
  const login = async (email: string, password: string) => {
    const response = await ApiService.login(email, password)
    user.value = response.user
    token.value = response.token
  }
  
  return { user, token, login }
})
```

### 4. API服务封装
```typescript
// 统一的API服务，支持Mock数据降级
export class ApiService {
  static async login(email: string, password: string) {
    try {
      const response = await apiClient.post('/auth/login', { email, password })
      return response
    } catch (error) {
      // 后端不可用时自动降级到Mock数据
      return this.mockLogin(email, password)
    }
  }
}
```

## 四、开发难点与解决方案

### 1. 响应式布局适配
**问题**: 目的地格子在不同数量时高度不一致
**解决方案**: 
```css
/* 使用CSS Grid和Flexbox结合 */
.destination-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 1.5rem;
  height: 500px; /* 4个格子时固定高度 */
}

.destination-item {
  min-height: 160px;
  display: flex;
  flex-direction: column;
}
```

### 2. 数据类型不匹配
**问题**: 后端返回的JSON字段与前端期望不一致
**解决方案**: 
```typescript
// 在API层进行数据转换
const transformProduct = (item: any) => ({
  id: item.id,
  name: item.title, // 数据库字段是title
  imageUrls: JSON.stringify([item.imageUrl || '']), // 转换为JSON格式
  facilities: JSON.stringify(item.facilities || [])
})
```

### 3. 前后端接口联调
**问题**: 开发阶段后端接口不稳定
**解决方案**: 
- 实现了Mock数据系统，确保前端开发不受阻
- 使用响应拦截器统一处理后端数据格式
- 实现了API降级机制，后端失败时自动使用Mock数据

### 4. 模态框组件设计
**问题**: 预订模态框样式和用户体验不佳
**解决方案**:
