该文件夹主要用于存放前端项目文件。

# 1. 环境准备

本项目的前端使用 Vue3 + TypeScript 编写，为了同时满足两门课的需求，故采用了 uni-app 来完成。

在开始之前，请确保你的电脑上安装了 Node.js 以及 pnpm ，前置均可使用 scoop 来进行安装。如果是使用 VSCode 推荐安装 Vue(officaial)、Markdown All in One 以及 Markdown Preview Github Styling 这几个插件。

# 3. 设计理念
本项目的设计理念基于以下核心原则：

- **优雅的极简主义美学**：注重内容与功能的完美平衡
- **清新柔和的渐变配色**：与品牌色系浑然一体
- **恰到好处的留白设计**：提升内容可读性
- **轻盈通透的沉浸式体验**：让用户专注于内容
- **信息层级清晰**：通过微妙的阴影过渡与模块化卡片布局
- **精心打磨的细节**：包括圆角、微交互和视觉比例

# 4. 设计规范
本项目采用了 uni-app 进行多端开发，以下为暂定的设计

## 一、 Wot-UI （组件库）

采用 Wot 作为组件库的主要原因有：
- 首先是设计风格契合本项目的轻量化、现代化和简约化，在视觉上弥补了 uni-app 无法使用 vue 的原生组件的困境。
- 同时由于它是为 uni-app 量身打造的，可以确保在 App、小程序、H5 等多端拥有一致且稳定的表现。
- 支持按需加载，不会使得应用程序变得臃肿，同样也支持主题定制，你可以根据需求调整颜色、字体等基础样式。


## 二、 配色规范

项目采用以下配色方案，确保视觉一致性和舒适的阅读体验：

| 颜色名称 | 颜色代码 | 浅色模式下的用途 | 深色模式下的用途 |
|---------|------------|-----------------|-----------------|
| **米白** | `#fcfbfa` | **主背景色** 页面的最底层背景。 | **主文字色** 大标题、重要文本，确保高对比度。 |
| **漆黑** | `#161823` | **主文字色** 对应米白背景上的标题和正文。 | **主背景色** 页面的最底层背景。 |
| **灰** | `#2b2b2b` | **次要文字色** 副标题、提示性文字。 | **卡片/控件背景** 浮动在主背景之上的卡片、输入框等。 |
| **檀木灰**| `#332f2c` | **边框/分割线** 用于分隔列表项或元素。 | **次要卡片/悬浮背景** 用于次级卡片或元素在鼠标悬浮时的背景色。 |
| **荷花** | `#fbede0` | **高亮区域背景** 需要突出显示的特定区域，如置顶公告、优惠券背景。 | **特殊点缀/高亮文字** 用于非常规的点缀性线条或需要强调的特殊文本。 |
| **松石绿**| `#325947` | **主引导色/行动色**  用于所有浅色背景上的可交互元素 |  |
| **薄荷绿**| `#A0D4C4` | （按下状态等细节点缀） | **主引导色/行动色** 用于所有深色背景上的可交互元素 |
